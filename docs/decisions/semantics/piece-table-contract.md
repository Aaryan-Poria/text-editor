# Piece Table Contracts

| Function                 | Preconditions                                                                                                                                                                                                                                                                                       | Postconditions                                                                                                                                                                                                                                                                                                      | Relevant invariants                                                                                                                                                       |
| ------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `PieceTable` constructor | None. Empty initial text is valid.                                                                                                                                                                                                                                                                  | `original` contains the initial text, `add` is empty, and `pieces` contains one piece referencing `original` if the text is non-empty. Otherwise, `pieces` is empty.                                                                                                                                                | Each piece references a valid range in its buffer. The pieces, in order, represent the document's text.                                                                   |
| `moveToPiece`            | `it` is a valid iterator into `pieces`, or `pieces.end()`. `remaining` does not exceed the total length of the pieces from `it` to the end. Private callers are responsible for satisfying these conditions.                                                                                        | If the position falls within a piece, `it` points to that piece and `remaining` is the offset within it. If the position is at the end of the remaining text, `it == pieces.end()` and `remaining == 0`.                                                                                                            | Does not modify the buffers or piece list.                                                                                                                                |
| `charAt`                 | `position` is less than the document length.                                                                                                                                                                                                                                                        | Returns the character at the requested logical position. The document remains unchanged.                                                                                                                                                                                                                            | Existing Piece Table invariants remain unchanged.                                                                                                                         |
| `getText`                | `start` is at or before the end of the document.                                                                                                                                                                                                                                                    | Returns up to `length` characters starting at `start`. If fewer characters remain, returns the text through the end of the document. Returns an empty string when `length == 0` or `start` is at the end.                                                                                                           | Does not modify the document or its buffers.                                                                                                                              |
| `cursorAt`               | `position` is at or before the end of the document.                                                                                                                                                                                                                                                 | Returns a cursor representing the requested logical position. At a boundary between pieces, the cursor points to the next piece with offset `0`. At the end of a non-empty document, it points to the last piece with offset equal to its length. For an empty document, it contains `pieces.end()` and offset `0`. | Does not modify the document. The returned cursor is valid for the current document state.                                                                                |
| `insertText`             | If `text` is non-empty, `cursor` must belong to this Piece Table and represent a valid position in its current state. For a non-empty piece list, its offset must be between `0` and the piece's length, inclusive. For an empty piece list, the cursor must contain `pieces.end()` and offset `0`. | If `text` is non-empty, inserts it at the cursor position and moves the cursor to the end of the inserted text. If `text` is empty, no state changes occur.                                                                                                                                                         | `original` is never modified. `add` is append-only. Every piece references a valid, non-empty range in its buffer, and the pieces represent the document's text in order. |
| `deleteText`             | `start` is at or before the end of the document.                                                                                                                                                                                                                                                    | Deletes up to `length` characters starting at `start`. If fewer characters remain, deletes through the end of the document. If `length == 0` or `start` is at the end, the document remains unchanged.                                                                                                              | Neither buffer is modified. The remaining pieces are valid and represent the updated document in order.                                                                   |

## Piece Table Invariants

- `original` is never modified after construction.
- `add` only grows by appending text.
- Every piece refers to a valid, non-empty range in either `original` or `add`.
- Reading the pieces in list order produces the document's current text.
- An empty document has no pieces.

## Cursor Validity

- A cursor represents a boundary between characters using a piece iterator and an offset within that piece.
- A structural edit can make previously obtained cursors stale. After an insertion or deletion, do not reuse older cursors. Obtain a fresh cursor with `cursorAt()` when needed.
- `insertText()` updates the cursor passed to it. That cursor remains usable until a subsequent structural edit invalidates it.

This is the policy for the current phase. Cursor tracking across edits can be reconsidered through targeted research when a later phase requires it.
